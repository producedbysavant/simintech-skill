# Запуск расчёта и получение результата

Проект для расчёта создаётся из шаблона, время расчёта задаёт `end_time` —
это описано в скилле `simintech-model-building`. Здесь — про сам расчёт.

## Инструменты

| Инструмент | Назначение |
|---|---|
| `create_project(end_time=N)` | Проект из шаблона + конечное время расчёта |
| `set_calc_time(N)` | Изменить конечное время расчёта (свойство `endtime`) |
| `run(to_time=N)` | Расчёт до момента N секунд |
| `step(n)` | N шагов расчёта (+0.001 модельного времени за шаг) |
| `stop()` | Остановить |
| `get_time()` | Текущее модельное время |
| `read_output_file(path)` | Прочитать результат, записанный блоком «В файл» |

## Результат получают через блок «В файл»

**Основной путь.** `get_signal` работает только у проекта с подключённой базой
сигналов (см. ниже), а блок «В файл» пишет результат всегда — в текстовый файл,
по строке на момент времени:

```
<время> <значение 1> … <значение n>
```

Рабочий порядок:

```
create_project(end_time=1.0)
add_block("Константа", props="a=2")                     # → k_0
add_block("Усилитель", props="a=3")                     # → kx_0
add_block("В файл", props="filename=<каталог результатов>\\out.txt,count=1,step=[0.2]")
connect("k_0", "kx_0")
connect("kx_0", "ToFile_0")                             # автоимя блока
run(to_time=1.0)
read_output_file("out.txt")                             # 0…1, значение 6 (2×3)
```

**Файл обязан лежать в каталоге результатов.** `read_output_file` читает
**только** его — это стандартное ограничение, а не опция. По умолчанию каталог
— `<временный каталог>/simintech-output`, переопределяется переменной
`SIMINTECH_OUTPUT_DIR`; точный путь печатает `help_text`, а также сам отказ при
попытке чтения снаружи. Относительный путь (`"out.txt"`) ищется внутри этого
каталога, поэтому в ответах блока и в `read_output_file` удобно использовать
одно и то же имя.

Свойства блока «В файл»: `filename`, `count` (сколько функций писать — равно
числу входов), `step` (массив шага записи, по умолчанию `[1]`), `fform`,
`strendformat`, `divstyle`. Блок пишет числа: массивы и структуры выгрузить
нельзя.

## `get_signal` требует базы сигналов проекта

`GetProjectSignalList` (COM) возвращает **только обменные сигналы** — созданные
блоками «Вход/Выход алгоритма» и подключённые к базе. У модели из шаблона базы
нет, поэтому:

- `list_signals()` честно скажет «читаемых сигналов нет» и отдельно покажет
  имена блоков схемы — их **нельзя** прочитать через `get_signal`;
- `get_signal("Блок")` вернёт ошибку, а не значение.

Если модель должна читаться через `get_signal`, в схему добавляют блоки
«Вход/Выход алгоритма» и подключают базу сигналов в самом SimInTech. Это
свойство среды, а не дефект модели. Для самодельной модели используйте
блок «В файл».

## Проверяйте модельное время, а не сообщение об успехе

`run()` сообщает «Расчёт не дошёл до N с: модельное время …», если время не
выросло. Причины, по которым это бывает:

- модель создана пустой (`NewProject`) — в ней нет расчётного слоя;
- **у какого-то блока висит неподключённый вход** (см. ниже);
- задан слишком большой `to_time`.

## Неподключённый вход молча останавливает весь расчёт

Проверено на SimInTech64: если у блока вход не соединён ни с чем, расчёт не
идёт **у всей модели** — `get_time()` остаётся `0.0`, и никакой ошибки при этом
не выдаётся. Схема «Константа → В файл» связана — время доходит до заданного;
та же схема с висящим входом у «В файл» — время `0.0`; одна «Константа» без
«В файл» — снова считается.

Поэтому, прежде чем искать причину в настройках: убедитесь, что у каждого блока
соединены все входы, и что числа входов хватает (у «Сумматора» их по умолчанию
два — лишние коэффициенты массива `a` портов не добавляют, нужен `in_ports`).

`RunTo` в этой сборке SimInTech **не блокирующий**: он возвращается раньше, чем
расчёт дойдёт до отметки (сразу после вызова время 0.240 с, через мгновение —
0.5 с). Поэтому `run(to_time=N)` дожидается отметки опросом `get_time()`, а при
простое ~1 с прекращает ждать. Если после `run` время `0.0` — расчёт не идёт.

## Порядок имеет значение

Параметры блоков устанавливайте **до** запуска: «Константа» и подобные
инициализируются в момент `ProjectStart`, и `set_block_param` во время расчёта
может не дать эффекта (`set_block_param` вызывает `InitBlock`, но надёжнее
менять параметры заранее).

## Платформа

COM API SimInTech работает только на Windows и требует зарегистрированного
сервера (`mmain.exe /regserver`). На других платформах `status()` вернёт
сообщение о несовместимости, а расчётные инструменты — ошибку.
